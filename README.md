# ZAYBA Download

A static download page for the ZAYBA project.

## Local preview

Serve the repository root with any static web server and open the site entry point through that server.

## Deployment checklist

- Confirm the production URL and hosting project before publishing.
- Verify the deployed page, download links, and browser console after each release.
- Keep privacy, terms, data-retention, and data-transfer details aligned with the actual production configuration.
- Do not publish until the responsible legal entity, contact details, retention periods, and hosting/data-region facts are verified.

Deployment credentials and provider-specific secrets must remain in the hosting platform, not in this repository.
